## 跨批工作约定

- **测试先行**：每批新功能先写 pytest 再实现（tdd）；批末全量跑 `pytests/`，基线只增不减
- **提交纪律**：`git add -- <显式文件>`；长中文正文走 `-F <UTF-8 文件>`；不 amend 已 push 提交；**push 一律交用户**
- **每批收尾三件事**：全量测试 → 更新登记表状态列 → HANDOFF §7 追加一行
- 中文字符串用「」；改完 `ast.parse()` 自检；新增 config 字段同步 `pytests/_synth_loader.py` 夹具
- **后台 LLM 纪律**（HDSI 运维事故族，2026-09-25 增补）：后台调用不得持有任何会阻塞入站消息的锁；「空结果」也是可持久化结果（防"无记录恒判 due"的重试风暴）；任何「降级」语义必须配注入故障的回归测试（防"注释说降级、代码在冻结"）；后台整理任务带来源版本+单调游标，防滞后回写旧状态
- **中文语义单一实现**：同一语义（命令判定、撞车判定、时间提取）在"检测侧"与"提示侧"必须共用同一份实现（HDSI"双侧失明"教训）

## 批 1：隐私止血 + 数据回路

**目标**：堵现行泄露事故（ADR-0004），让闸门重新有数据（ADR-0005）。

1. **store schema**：chronicle 表加 `kind`（已有则规范）/`source_uid`/`audience` 列（ALTER TABLE）；pending_events 条目结构加 `source_uid`
2. **存量打标**：一次性 SQL 将现存 18 条 `kind=diary` 标 `source=diary`（不清洗不删除，仅隔离）
3. **`narrative_chronicle_append` API 加 audience 参数**（R13：diary 侧未适配前先收后打标）
4. **`render/audience.py`**：ADR-0004 规则表实现——注入与取材统一走它过滤；`kind=diary` 对 narrative **所有消费路径短路**（不注入、不进创作层）
5. **`proactive/sourcing.py`**：取材按当前会话受众过滤；world_view/life_goals 相关素材此批还未诞生，规则先落 audience 维度
6. **is_command 本地正则**（R9）：入站 hook 里本地判定命令文本，不进素材、不刷关系值、不进指标
7. **tier→详略档**：sourcing 不再按 tier 一票否决；取材优先级改为「未用过（bysource:used 去重）且与最近对话不撞车（轻量文本重叠判定）」；tier 只决定注入展开详略
8. **指标 4 双轨埋点**：A 轨（快照状态组合 distinct 熵）随 `state/snapshot.py` 落；B 轨（产出多样性）两法并埋对比（embedding vs 字符 n-gram，R7 选型本批定）
9. **回放台初版 `tools/replay/`**：输入=归档插件数据（`E:\Downloads\MaiBot\data\MaiMBot-plugin-data/...`）+ `E:\Downloads\MaiBot-export\messages.jsonl`（CLI 传路径，不硬编码不入库）；首个用例=**泄露事故重放**（`2562838066` 09-20~21 消息序列 → 断言对 `927386371` 的注入/由头 0 命中其涉私内容）
10. **计数器通道**：telemetry 通道扩展出通用计数器接口 + 四指标 csv（提案/晋升/反证/回滚），批 4 晋升机写入——HDSI 到 1.0.1 都没有晋升频率数据，门槛至今拍脑袋，我们不能再盲（R17）

**闸门**：回放台泄露用例 0 命中；指标 4 A/B 轨对 26 天归档数据出数（B 轨基线值 → 登记表 R8 定铺群闸门判据）；全量测试绿。

5. **仿真适配器 E2E 脚本**（`tools/replay/` 或 `tools/sim/`）：按 NapCat WS 协议注入 MaiBot-export 消息帧 → 断言 replyer 请求含 `_narrative_style_` item、原 kwargs 无丢失、planner 注入不回归

## 批 4：慢变区（晋升机全量 + 写回）

**目标**：ADR-0002 §3~6——漂移→慢变晋升闭环，重构主峰。

1. **`learning/proposal.py`**：周度 LLM 提炼 → 受控维度提案（只能提 target/path/proposed_value/evidence/confidence，白名单外拒绝）；提炼 prompt 内置 HDS 负面清单：「口吻/回复模式/昵称/散文节奏/暂时性情绪=本场戏证据，不是发展倾向」；**学习输入掩码**：world_view/life_goals 提案证据不得引用特定用户私聊原文，relationship 按用户隔离
2. **`state/continuity.py` 晋升机**：minor(≥0.82/≥3场景/≥2天/72h冷却)、major(≥0.95/≥2场景，默认关)——全部配置项（R4/R5 待回放定标）；同场景只计一次；重复合并 +0.05；反证 −0.2 → rejected；关系类须「用户真实反馈+角色实际回应」证据链；审计写 `promotions` 表 + chronicle `kind=promotion`
3. **tomlkit 写回 `[learned]` 投影**：不声明进 config.py（WebUI 不渲染）；`on_config_update(scope="self")` 防重入；投影损坏可从 db 重建
4. **读取端限流**：慢变字段按相关度最多投影 2 条软倾向进注入块（措辞：「是倾向，不是必需反应，不是不变身份」）
5. **回滚**：按 `promotions` 表逆序恢复旧值（用户定义「小步可动，须留痕」的闭环）
6. **证据纪律五条代码级落地**（ADR-0002「证据纪律」）：认知模式标签（观察/转述/信念/提议/条件/确认+主体）、来源桶标签（独立生活/私聊/群聊）、反证受控枚举匹配、「用户反馈 id→已送达回应 id」配对、**输入充分性断言**（回放台正向验证：输入充分时能产出非空提案——防 HDSI Agency"恒空"式失效）
7. **慢变 seed**：上线时从锚定层派生 `origin=seed` 初始值（ADR-0002「冷启动」，R15）；seed 与晋升值同受反证管辖
8. **通信事实标记**（ADR-0003 §8）：创作/注入合约「通信事实以宿主账本为准」，片段中"已发送"只能写意图；注入块可带最近真实发送清单
9. **晋升计数器写入**四指标（批 1 通道，R17）

**闸门**：回放台喂 26 天全量数据 → 晋升产出节奏合理（不过密/不为零），据此**定标 R4/R5 并固化默认值**；输入充分性断言通过；仿真 E2E 全链（素材→生活片段→提案→晋升→注入→回滚）。
