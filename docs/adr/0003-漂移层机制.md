# ADR-0003：漂移层机制——规则调制 + 原文连续性

- 状态：已接受（2026-09-24）
- 关键证据：`.workbuddy/HDSI漂移与素材隔离专题调研-2026-09-24.md`（HDSI 源码级核查）

## 背景

漂移层"句长语气措辞"的学习源有两个候选：学用户（MaiBot 原生表达学习的职责域）或学自己（生活线驱动）。用户裁定：**漂移层由自己的生活线决定**。HDSI 专题调研进一步证实：HDSI 全系统**没有任何 LLM 提炼的风格描述字段**——风格连续性 100% 靠 recentScript 原文续写；唯一的 LLM 提炼字段（Alter `emotionalOffset.description`）在 beta8 发生「提炼描述被模型当写作模板→结构固化→自我强化」实机事故，修复代价是四件套护栏（内容域收窄/负面清单/防自举/主权声明）。

## 决策

1. **一期机制 = 规则实时调制 + 原文连续性**：
   - 规则调制：mood/energy/作息相位 → 本轮表达提示（确定性映射表，零 LLM），经 replyer 通道注入（ADR-0005 批 3）
   - 原文连续性：生活片段/编年史原文注入本身就是文风载体——narrative 已有的 chronicle 注入即 HDSI recentScript 的对位物
   - 话题偏好：从生活线/hot_thread 替代品（生活片段主题）确定性累积，不经 LLM
2. **不做 LLM 风格提炼字段（一期）**。二期可选（登记表 R1/R3），启用前置条件：
   - 实机观察证明原文连续性不足以产生可感漂移
   - 且必须同时上齐 HDSI 四件套：内容域收窄（只许"可消退的内在状态+具体原因"）、负面清单（禁 speaking instruction / style template / suggested wording）、防自举（提炼产物不作为下轮评分与续写证据）、主权声明（内容归当前对话，调制只许着色节奏形态）
3. **表达学习隔离 hook 保留**（`expression.select.before_select` + `expression.learn.before_upsert`，现 plugin.py:445/465）：
   - 原生表达学习定位 = 群聊场景、人工审核入库、调用时实时取、不进记忆（用户说明）
   - select 阻断防已审核群腔调进私聊剧本会话；learn 阻断防剧本素材进表达库——两者理由在漂移层自驱方案下**依然成立**
4. **群聊三轨（寒暄接梗→表达库 / 剧本生活→漂移层 / 平时混合）**：立项已有共识（mount-points §7），本期只在 `render/track.py` 留接口，**实现冻结**。解冻条件 = 用户宣布铺群；接口删除条件 = 群聊方案废弃（登记表 R2）。
5. **replyer 注入通道**（批 3）：
   - hook 选 `maisaka.replyer.before_model_request`（改实际 Context Items；宿主 1.2.0 已存在，`maisaka_generator_base.py:765`）
   - 宿主 `[personality].reply_style` **不清空不迁移**：宿主基线管"她是谁的口吻"，插件注入增量调制层管"她此刻的状态"，叠加语义，关插件即回退
   - 注入物规范：marker 前缀 `_narrative_style_`（与 `_narrative_life_context` 不互为子串）；**必须回并原 kwargs**（宿主 `modified_kwargs` 是整体替换非合并——private-humanizer 踩实的坑）；内容 = 规则调制描述 + `[learned]` 预留槽（v1 恒空）+ audience 过滤后的关系语境一句话
6. **文学授权与调制规则分离**（2026-09-25 grill Q3 通过，HDSI beta9~beta12 两轮回填的教训）：
   - 注入块措辞分「调制段」与「授权段」：调制段（疲惫→短句等）可收紧可放宽；**铺陈/文学授权段只增不删**
   - 禁止在注入块堆砌「Do not output」式禁令组——禁止性说明文本本身就是写作模板（HDSI"五步仪式"事故根因）
   - 任何提示词精简/压缩改动必须过回放台注入前后对照样本；措辞敏感项（如字数上限）用区间表述不用"上限"（"800 字上限被读成天花板、正文腰斩"事故）
7. **话题偏好外部加权**（2026-09-25 grill Q3 通过）：话题偏好的累积以「用户实际接话（回复/追问）的互动事件」为主要证据源；生活片段自身主题降权——防自主信息茧房（她写猫→素材全猫→对人人讲猫）。加权系数为待观察参数（登记表 R16）。
8. **通信事实标记**（2026-09-25 grill Q4 通过，借 HDSI `no-outgoing-action-recorded` 语义）：创作与注入合约明文「通信事实以宿主账本为准」——生活片段里"我回过你"只能以意图形态出现（"想回你"）；注入块可带最近真实已发送清单。防"片段虚构了发送、下轮当成事实引用"（"就我刚才说的"而用户毫无记忆）。
