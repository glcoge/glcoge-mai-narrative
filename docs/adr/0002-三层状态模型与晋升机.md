# ADR-0002：三层状态模型与晋升机

- 状态：已接受（2026-09-24）
- 依赖：ADR-0001（布局与批次）；权威三层定义见 `.workbuddy/HANDOFF.md` §2.3（用户 2026-09-24 裁定）

## 三层归属（权威口径，不改）

| 层 | 内容 | 归属 | 变化规则 |
|---|---|---|---|
| 锚定层 | 名字/身份/长期性格/价值观底线 → 宿主 `[personality]`；世界观与规则 → 插件 config | 配置 | 永不改变 |
| 慢变区 | 对世界的看法 / 人生目标 / 长期关系 | 插件 config（`[learned]` 投影）+ db 事实源 | LLM 提案 + 宿主门槛审计晋升，小步可动、须留痕、可反证回退 |
| 漂移层 | 句长语气 / 话题偏好 / 作息 / 情绪精力 | 插件运行时状态 + 规则 | 由自己的生活线驱动，见 ADR-0003 |

## 决策

1. **慢变区白名单字段（受控维度，LLM 不得自由开字段）**：
   - `perspective.world_view`（对世界的看法，文本）
   - `perspective.life_goals`（人生目标，数组）
   - `relationship.trust`（信任）/ `relationship.closeness`（亲密度）/ `relationship.boundaries`（边界感）/ `relationship.stage`（阶段标签，由前三者+证据晋升产生，**可回退**）
   - **明确排除 `character.traits` 等人格维度**——锚定层人格归宿主 `[personality]`，让 LLM 学 traits 等于把双人格事故从后门放回来。
2. **关系线全量替换（用户裁定）**：旧规则线 `stage/familiarity/trust`（只进不退）**废弃**，由晋升线接管呈现。内测期数据少、变更成本低，不留双轨。
   - `first_met` / `milestones` 是**事实**不是演化观点：保留为只读事实字段，不参与晋升。
   - 互动计数器保留但降级为**内部证据计数**（不进注入块、不进 `/narrative status`），作为晋升证据链的确定性时间戳来源。
3. **晋升机数值照抄 HDS 实测值，全部做成配置项**：
   - minor：置信 ≥0.82 + 跨 ≥3 场景 + 跨 ≥2 自然日 + 同 path 72h 冷却
   - major：置信 ≥0.95 + 跨 ≥2 场景（快速通道，默认关）
   - 反证：confidence −0.2、status=rejected；情绪/情境特例不算反证
   - 同场景只计一次；重复提案合并且置信只 +0.05（反复叙述不加信）
   - 关系类晋升必须有「用户真实反馈 + 角色实际回应」证据链
   - 场景计数映射：**1 个生活片段 = 1 场景；1 个互动日 = 1 场景**
   - 数值不凭感觉改：由回放台喂 26 天真实数据定标（登记表 R4/R5）
4. **晋升机状态存 sqlite**（`narrative.db` 新增两表，store.py 扩展）：
   - `proposals`：target / path / proposed_value / confidence / status(pending|applied|rejected|rolled_back) / evidence_refs / source_uid / created_ts / updated_ts
   - `promotions`：审计表，applied/rejected/rolled_back 全记，含旧值新值
   - 人可读留痕走 chronicle `kind=promotion` 条目；原方案的 `slow_change_log.jsonl` **作废**（单一事实源原则）
5. **读取端限流（防晋升后写死）**：慢变字段不整段注入，按相关度最多投影 2 条「软倾向」进 prompt，措辞遵循 HDS 纪律「是倾向，不是必需反应，不是不变身份」。
6. **`[learned]` 区块不声明进 `config.py`**（WebUI 不渲染即不回写，规避 stale 覆盖）；tomlkit 增量写回自身 config.toml（`glcoge-group-admin` 先例），`on_config_update(scope="self")` 必须防重入。`[learned]` 只是**呈现层投影**，事实源在 db——投影损坏可从 db 重建。
7. **存量数据处置：state 重置、chronicle 保留**。旧 state JSON 无三层字段，不写迁移器（不为死格式陪葬）；新库带 `schema_version`。chronicle 是编年史原文、晋升机证据源，必须保留；其中 diary 条目按 ADR-0004 完全隔离。用户已确认：内测期关系数据对真实聊天感受几乎无影响，只要聊天记录与 A_Memorix 不重置即可。
8. **死字段处决清单**（批 0/批 2 执行）：`habits`、`shared_secrets`、`user_notes`、`hot_thread`（死+曾被污染）、`events.declared`（死列）——全部删除，不留兼容。
9. **锚定层护栏**：
   - 启动期「宿主 `[personality]` vs 插件 world/values」LLM 一次性一致性比对 → 不一致仅 WARN 不阻断（真机已出现"大二女大学生 vs 隐姓埋名神兽"双人格混写产物）
   - 锚定字段白名单常量；漂移/慢变写入路径显式排除锚定字段；pytest 锁死「锚定层永不被写」
   - LLM 产出双向守卫：入库前 + 注入前（学 private-humanizer）

## 证据纪律（2026-09-25 HDSI 踩坑全史核查后增补，grill Q1 通过）

提案必须满足五条**代码级硬规则**（不是提示词级；事故依据见主仓 `.workbuddy/HDSI三层机制踩坑全史-2026-09-25.md`）：

1. **证据锚原文 + 认知模式**：提案证据只允许引用 chronicle/生活片段的**原文条目**，并带认知模式标签（观察/转述/信念/提议/条件/确认 + 认知主体）。禁止以 AI 摘要、旧提案、复述内容为证据；复述不增信（置信仅新场景 +0.05，见决策 3）。事故原型：条件句「如果电影好看想再看一次」被反复转述固化成无条件承诺 → 「被爽约」怨恨（与温水杯回注同构：模型产物循环喂回模型）。
2. **来源桶标签**：证据带来源桶（`独立生活` / `私聊:{uid}` / `群聊:{gid}`）。`world_view`/`life_goals` 的晋升证据**不得单一来自某私聊**——单聊原文禁升格全局维度，代码级丢弃而非提示词劝阻；`relationship` 按 uid 隔离。
3. **反证匹配用受控枚举**：反证以「维度 + 场景条件枚举」受控键定位目标提案，不用自由文本相似度（HDSI 字面归并器「短声明误并、长改写漏并」为作者知情未修的漏洞）；短声明设合并下限。
4. **关系证据链配对**：relationship 晋升必须携带「用户反馈消息 id → 角色**实际送达**的回应 id」配对且回应晚于反馈；角色在生活片段/编年史里自己的解释**不算用户认可**（protest ≠ closeness，HDSI「19:39 抗议」事故：抗议被学成亲密证据）。
5. **输入充分性审查**：回放台对每个提案通道断言「输入充分时能产出非空提案」——HDSI Agency 教训：失败模式不是提错，而是**输入里没有提案所需信息导致产出恒空**、功能上线即形同虚设。

## 冷启动：慢变区 seed（2026-09-25 grill Q2 通过）

`world_view`/`life_goals` 上线（批 4）时从锚定层（world/values）派生 seed 初始值，标 `origin=seed`：
- seed 是晋升 diff 的基线——「她的看法何时、因何证据变过」从第一天起可叙述
- seed 与晋升值同受反证通道管辖，可被推翻
- 不设 seed 则晋升机无「现值」可提案，上线即恒空（冷启动死锁）；登记表 R15

## 脏数据政策（2026-09-25 grill Q5 通过）

**保留 + 读取端降权，永不回溯清洗。** 被污染的 chronicle/晋升历史原样保留、新旧分开、读取降权——清洗会销毁「污染如何发生」的现场，且装新版不会让旧事故自己消失（HDSI 全仓库一致选择：旧事实不清洗只标未分类降权）。批 2 的 state 重置属「换代」而非清洗，与本条不冲突。
