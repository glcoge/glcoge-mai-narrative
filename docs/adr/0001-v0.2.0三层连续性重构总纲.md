# ADR-0001：v0.2.0 三层连续性重构总纲

- 状态：已接受（2026-09-24，用户三轮 grill 逐项拍板）
- 基线：v0.1.10 / `f1065e7` / 175 测试全绿
- 前置调研：`.workbuddy/全量架构解析报告.md`、`.workbuddy/HDS幕间系统源码调研-2026-09-24.md`、`.workbuddy/HDSI漂移与素材隔离专题调研-2026-09-24.md`（均在主仓 `.workbuddy/`，不入插件仓）

## 背景

narrative 的问题不是缺功能，而是**管线断裂 + 无数据回路**：创作层 26 天产出 100% minor → 由头通道全量丢弃（`bysource:used:*` 0 条实证）；指标 4 从未埋点 → roadmap 闸门空转；三层骨架字段死置（`habits`/`shared_secrets`/`user_notes` 零实现）。路线漂移考古已归因：问题驱动排程只会修"会出 bug 的层"，缺数据回路的层安静地烂掉。

## 决策

1. **重构主轴**：从「数值状态机 + 文档承诺」切换到「证据链驱动的三层连续性架构」，且**先修数据回路、再建三层**。
2. **模块布局 = 全量重组（C 案）+ 纯移动先行**：
   - 批 0 第一个提交只做机械搬移 + import 改写，**零行为变更**，175 测试全绿锁底；此后每批只动自己目录，回归可二分定位。
   - 理由：离线窗口期是重组成本最低的唯一时机；部署加功能后再拆成本剧增（用户论点，采纳）。
3. **目标布局**（2026-09-25 修正：批 0 只做**整文件搬迁**，`NarrativeEngine` 类拆分推迟到后续批次——拆类必改签名，与批 0 零行为 diff 冲突；括号内为文件就位批次）：

```
plugin.py（接线层）  config.py  _manifest.json  CONTEXT.md
services/
  state/      engine.py（批0整文件迁入；批2拆出创作/编年史方法后余状态规则主体）
              continuity.py（批2建：白名单 schema；批4填晋升状态机+留痕）
              snapshot.py（批0，原 telemetry.py 整文件改名迁入）
  creation/   creator.py（批0整文件迁入）
              life.py（批2从 engine 拆出）  chronicle.py（批2从 engine 拆出，+受众标签）
  proactive/  scheduler.py（批0，原 proactive.py 整文件迁入）
              sourcing.py（批1从 engine 拆出 build_bysource 等，顺带 tier→详略档改造）
  render/     planner_block.py（批0，原 render.py 整文件改名迁入）
              replyer_block.py（批3建）  audience.py（批1建）  track.py（批0空占位，R2 冻结）
  learning/   drift_style.py（批3建：规则调制）  proposal.py（批4建：慢变提案审计）
  store.py（不动）  message.py（不动，消息字段访问共享 seam）  streams.py（不动，StreamRegistry）
tools/replay/（批1建：回放台，正式验收工具，进 git）
```

4. **批次与闸门**（过闸才进下一批）：

| 批 | 内容 | 闸门 |
|---|---|---|
| 0 | 纯移动重组 | 175 测试全绿、零行为 diff |
| 1 | 隐私止血（受众标签+过滤）+ 数据回路（is_command 修、指标 4 埋点、tier→详略档） | 回放台泄露用例 0 命中；指标 4 出数 |
| 2 | 护栏+schema（continuity 模型、锚定一致性 WARN、双向守卫、schema_version 重置） | 新 pytest + 回放台喂 26 天数据晋升机产出合理 |
| 3 | 漂移（replyer 注入通道 + 规则调制） | 仿真 E2E：风格注入可见、modified_kwargs 回并无丢失 |
| 4 | 慢变（晋升机全量 + tomlkit 写回 + 留痕回滚） | 回放台定标晋升数值 + 仿真 E2E 全链 |

5. **版本策略**：开发期每批打 `0.2.0-alphaN` tag；全部过闸 + 真凭证人工审后发 `v0.2.0`。
6. **增量而非重写**：2400 行既有代码与 26 天真机数据是资产；新能力长在深模块（continuity/learning），旧管道只改接线。
7. **预留接口登记制度**：所有预留接口/字段/待观察参数必须登记 `docs/预留接口登记表.md`，代码处 `# RESERVED(Rn)` / `# OBSERVE(Rn)` 注释锚定——根治 `habits` 式死字段复发。

## 不做的事

- ❌ 群聊扩展与受众抽象 `u:/g:` 命名空间（冻结，解冻条件见 ADR-0003）
- ❌ 从主程序 `[personality]` 收回人格（锚定层人格由宿主决定，`6139957` 方向不回退）
- ❌ 大范围主程序改动（「定制版」授权仅限插件难触及的小范围；本期预计零主程序改动，22 个命名 hook 足够）
- ❌ 人格/角色扮演约束写死进代码
