# ADR-0004：素材隔离（audience）四层强制

- 状态：已接受（2026-09-24）
- 关键证据：HDSI 三层宿主强制隔离（写入打标/读取过滤/学习输入掩码，见专题调研）；真实事故：`2562838066` 09-20 加入 → 09-21 进日记 → 09-22 泄露到 `927386371` 的主动消息
- 机制链定位：`.workbuddy/全量架构解析报告.md` §4（diary `filter_mode="all"` 全量抓取 → 全文 push 进 chronicle → 注入不区分 kind/受众）

## 决策：四层隔离

1. **写入打标**：chronicle / pending_events / 事件素材落库即带 `source_uid` + `kind`（diary 桥接 append 接口加 audience 参数）。
2. **读取过滤**：注入与由头取材按当前会话受众过滤，规则表一张定死：

| 素材 | 标签 | 可注入范围 |
|---|---|---|
| 生活片段（创作层消化产出） | `source_uid` 溯源 | **通用**（全用户） |
| chronicle `kind=life` | 同上 | 通用 |
| chronicle `kind=diary` | `source=diary` | **完全隔离**（见下） |
| chronicle 涉私原文条目 | `source_uid=A` | 仅 A 的会话 |
| pending_events | `source_uid` | 仅该用户会话取材；无标签通用片段全员可用 |
| relationship 慢变字段 | per-user | 仅该用户会话 |
| world_view / life_goals | 无（晋升时已排除私聊原文） | 通用 |

3. **学习输入掩码**：慢变晋升的证据审计执行 HDSI 同款规则——`world_view`/`life_goals` 晋升证据**不得引用特定用户私聊原文**（只能用消化后的事实摘要）；`relationship` 晋升按用户隔离。没有这层，慢变区会把用户 A 的私聊观点晋升成"对世界的看法"再讲给 B——比日记泄露更隐蔽。
4. **创作层输入边界**：生活片段生成可用**跨用户的结构化事件摘要**（生活线是主角统一记忆，对应 HDSI advance 回合的全量事实通道），但摘要须带来源标签可溯源；**原文级对话不进创作 prompt**。没有这条边界，创作层会被隔离到无米下锅。

## diary 产物完全隔离（用户裁定，严于原案）

依赖方向是 **diary → narrative 单向**（diary 是后置附属），narrative 绝不消费 diary 产物：

- chronicle `kind=diary` 条目：**不注入任何会话、不进创作层消化**，仅存档
- 现存 18 条 diary 条目直接按隔离处理，不清洗不迁移
- `narrative_chronicle_append` API 保留（diary 侧继续写、带标签），但 narrative 侧所有消费路径对 `source=diary` 一律短路

## 边界声明

本 ADR 只有私聊用户维度，**不是**被冻结的群聊受众抽象（`u:{uid}`/`g:{gid}` 双命名空间随铺群解冻再设计）。它是立项铁律「涉私内容不进生活线（对外）」在数据结构上的落实。
